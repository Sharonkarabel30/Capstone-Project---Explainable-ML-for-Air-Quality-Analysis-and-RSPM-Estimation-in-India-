# Predicting RSPM (PM10) Air Pollution Across India

**AAI-590 Capstone Project — Master of Science in Applied Artificial Intelligence**

This project predicts the daily concentration of Respirable Suspended Particulate Matter (RSPM, PM10) at Indian air-quality monitoring stations. It compares four traditional machine-learning models with two neural networks, explains the best model with SHAP, and deploys the final models in an interactive dashboard.

## Data

*India Air Quality Data* — Kaggle, `shrutibhargava94/india-air-quality-data` (Central Pollution Control Board, 1987–2015, 435,742 records). The raw data is not stored in this repository; the notebook reads it from Kaggle.

## Methods

- **Cleaning:** duplicates, missing targets and invalid dates removed (395,029 records kept); duplicate category labels merged.
- **Features:** SO₂, NO₂, state, city, area type, year and cyclical month encoding.
- **Split:** chronological — train 2003–2012, validation 2013–2014, test 2015.
- **Models:** median baseline, Ridge Regression, Random Forest, XGBoost, feed-forward MLP and entity-embedding neural network (Keras).
- **Optimisation:** hyperparameter tuning of Ridge, XGBoost and the neural network on the validation years.
- **Explainability:** SHAP (TreeExplainer) for XGBoost, plus per-prediction explanations in the dashboard.
